# 🇮🇳 DRDO NEXTGEN

A futuristic and responsive landing page inspired by next-generation defence technologies, featuring an interactive navigation menu, modern UI design, and smooth user interactions.

## 🚀 Project Overview

DRDO NEXTGEN showcases emerging defence technologies such as:

* Advanced Defence Systems
* AI & Autonomous Warfare
* Space & Strategic Defence
* Innovation Dashboard

The project was developed as part of **SkillCraft Technology Internship – Task 01**.

---

## ✨ Features

* Fixed Navigation Bar
* Interactive Hover Effects
* Dynamic Navbar Style Change on Scroll
* Glassmorphism UI Design
* Responsive Layout
* Smooth Scrolling
* Scroll Reveal Animations
* Modern Defence Technology Theme

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
